# Step 10.1 to 10.2 Handoff

## Completed boundary

Milestone K Step 10.1 is limited to deterministic local quality hardening. It
adds no backend feature or production runtime. The completed boundary provides:

- an explicit `pytest --cov --require-local-release` gate that fails instead of
  silently skipping required local evidence;
- read-only verification of distinct restricted `pl_platform_dev` and
  `pl_platform_test` targets at exact head `f0009_step_7_9`;
- complete verification of all eleven historical raw captures through the
  existing manifest boundary;
- verification that the actual registry contains exactly one history ending at
  `development_accepted` and no active model;
- exact Alembic file, head, parent, branch-label and dependency-edge checks;
- a full head-to-base and incremental base-to-head migration cycle supplied
  only with the test connection and rolled back by its caller-owned transaction;
- exact runtime/development dependency pins, installed-version comparison,
  64-bit Python 3.14.7 and local `pip check` consistency; and
- an isolated package-wide import sweep that blocks external constructors and
  requires no filesystem output.

The ordinary pytest mode remains portable. The explicit release mode is the
required local backend-release evidence and does not accept PostgreSQL, raw-data
or registry skips.

## Preserved contracts

- Development and test PostgreSQL remain distinct; the migration cycle never
  supplies the development connection to Alembic and restores test state.
- Production database selection still fails closed.
- Every normalized repository write still begins with verification of all
  historical raw captures.
- The FastAPI surface remains exactly sixteen GET operations with the existing
  request-ID, error-envelope, pagination, OpenAPI, CORS, security-header and
  rate-limit contracts.
- The actual registry remains `development_accepted`; there is no active model
  and no registry event was written.
- The sealed 2025–26 target was not inspected and no final-test evidence was
  created.
- No artifact corpus was imported or modified. No provider was selected or
  contacted. No prediction, scoreline distribution or simulation was produced.
- Module imports remain side-effect free and runtime dependencies remain lazy.
- No dependency, external vulnerability service, automation, scheduling,
  recurring monitor, CI/CD, GitHub Actions, container, deployment or hosted
  infrastructure was added.

## Verification command

Run the complete local gate from the project virtual environment:

```powershell
ruff check .
ruff format --check .
mypy src tests migrations
python -m pip check
pytest --cov --require-local-release
```

Also run `git diff --check` and the local Markdown-link check before closeout.

handoff. After separate explicit approval, it will define and locally verify a
reproducible non-root container for the existing FastAPI backend, its explicit
ASGI startup command, production environment validation, secret-free runtime

remains Step 10.4; provider selection, artifact import and all later Milestone K
work also remain outside this handoff.
